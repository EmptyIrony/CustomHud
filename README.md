# CustomHUD

CustomHUD 是一个车载 Android 应用，在车机副屏（HUD / 仪表）上叠加自绘画面，显示时钟、车况、歌词和后视摄像头画面。目前主要在 ZEEKR 007（Android 12 / SDK 32）上开发和实测。

> [!WARNING]
> **驾驶安全第一。** 本软件是个人爱好项目，不是原厂功能，也不是安全设备。安装或使用前请先读完下面的[免责声明](#免责声明)。

## 功能

- **HUD 叠加层**：在选定的副屏上用透明悬浮窗显示 View/Canvas 自绘内容，布局可视化编辑，支持导入导出。
- **时钟与车况**：通过公开的 `android.car` 车辆属性只读获取车速、挡位、电量、续航、功率、转向灯、胎压等；读不到的字段显示“不可用”，不会编造数值。
- **大字歌词**：从媒体会话、媒体通知或歌词接口读取当前歌词，支持多种动效、按宽度自动缩放和长句拆分。
- **后视摄像头**：非 P 挡时在仪表屏显示后视画面（依赖车机自带的相机服务）。
- **探测与日志**：只读汇总权限、屏幕、媒体字段和车辆属性，分页显示，方便在车里拍照记录。
- **PREVIEW 模式**：在普通窗口中用模拟数据预览布局，不需要连接车辆。

## 运行要求

- Android 10 及以上（minSdk 29，targetSdk 34）。
- 应用以系统共享 UID（`android.uid.system`）运行，**只能装在接受 AOSP 平台测试密钥签名的车机上**。正式车机系统一般会拒绝安装。
- 车辆数据、副屏输出和摄像头能否使用，取决于具体车型、系统版本和厂商限制，不保证在别的车上能用。

## 构建

工具链：JDK 21、Gradle Wrapper 8.14.3、AGP 8.13.2、Kotlin 2.0.21、compileSdk 34。

```bash
# Mac / x86 主机
./gradlew clean testDebugUnitTest lintDebug assembleDebug assembleRelease --no-daemon

# Linux arm64 开发容器（用 CarLight 工具链，在临时副本中构建）
tools/build-linux-arm64.sh
```

上车安装前，APK 要用平台密钥重新签名。本仓库**不包含**任何签名密钥。签名、手动验收步骤和架构说明见 [`BUILDING.md`](BUILDING.md)。
