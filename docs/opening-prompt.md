# 开场任务

请先读取附件接口包，再开发我的独立 Android 车载 HUD 应用。

开发环境是新的，不依赖我的电脑目录、工具安装或已有工程。附件是非官方兼容性接口草案；其中 Android 公共 API、平台适配候选和需要新项目实现的接口约定已经区分。待验证能力不能当作厂商保证，也不要凭空补造设备协议。

请依次读取 README、platform-interface、lifecycle、layout-and-rendering、data-interfaces、implementation-and-acceptance，再检查 schema 和示例。

要求：

1. 先检查当前开发环境，说明技术栈、最小架构与实施顺序，然后创建独立工程并继续实现。默认采用 Kotlin 与 View/Canvas；若环境需要改变，集中说明关键选择。
2. 先完成可构建的 PREVIEW 模式、模拟数据、版本化配置、Canvas 渲染、会话状态机、启动/停止和可见日志，再接 DEVICE 副屏窗口。
3. 严格实现生命周期、幂等、失败回滚、屏幕变化恢复、权限变化、会话 generation 和资源清理。区分服务存在、窗口添加、View 附着、绘制和实际显示确认。
4. 车辆数据只读，各数据源独立；每字段保留来源、单位、真实采样时刻、未知/过期状态。缺失 SDK 或权限时用明确的不可用状态和 mock，继续完成其他离线工作。
5. 遵循版本化布局 schema，完整替换必须全量校验后原子提交。新的自定义内容类型作为项目扩展单独定义。
6. 完成必要的行为测试与实际可执行的离线构建，交付工程、构建说明、结果、APK 和哈希。没有实车验证的能力明确保留为待验证。
7. 现场安装、连接车辆、启动显示或改配置，由我确认后手动执行；当前先完成离线开发。遇到明确安全拦截，停止相关操作并说明。

请现在开始检查环境并推进开发，不要只回复一份计划。
